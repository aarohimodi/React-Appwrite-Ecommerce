# E-Commerce Website

A simple e-commerce website built with React and Appwrite. Users can browse products, view product details, add items to their cart, and manage their wishlist.

## Features

- User signup and login
- Product listing and product details
- Add to cart and wishlist
- Cart and wishlist management
- Admin product management
- Category management
- Responsive design

## Tech Stack

- React
- Vite
- Tailwind CSS
- Appwrite
- Redux Toolkit
- React Router

## About

This project was built to practice React concepts, state management, authentication, and backend integration using Appwrite.
